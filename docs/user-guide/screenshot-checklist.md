# Candidate screenshot and walk checklist

**Status: Not walked on a candidate build.** Capture only after the exact build and rig are recorded. Use a 1280×800 pt operator window plus the named camera/output route. Do not substitute the Debug Multiview gallery for the current operator window.

| View / state | Screenshot file | What to verify live | Result |
| --- | --- | --- | --- |
| Stopped screen | | “Alfie is standing by”, Start session, inspector handle | Not run |
| Settings → Composer | | Format Stage/Webcam and active preset | Not run |
| Settings → Output | | Show Standard, Preferred Route, diagnostics Open in Finder | Not run |
| Running, no lock | | One source and crop view; Detect, Pick subject, pill fits | Not run |
| Detect armed / acquiring | | Tap affordance, Cancel, Acquiring… | Not run |
| Locked tracking | | Locked, Crop, shot ladder and tap Push in/Pull out | Not run |
| Recovering HOLD | | Recovering, last good picture, 10-second lock HOLD | Not run |
| Searching / Resume | | Searching after HOLD; Resume only with retained gallery evidence | Not run |
| Pick subject fallback | | No retained evidence yields Pick subject; new tap acquires | Not run |
| Return to Wide | | Uncropped feed, lock cleared, stale Resume rejected | Not run |
| Manual and Auto Pan | | Their controls and pointer/Detect behavior | Not run |
| Inspector → Pipeline stages | | Stage rates and “unknown” downstream presentation | Not run |
| Inspector → Setup check | | Provisional result/reasons, not a certification claim | Not run |
| Webcam fallback | | Below-show-rate camera status and actual delivered rate | Not run |
| Output loss / reconnection | | Explicit route status and no unsupported downstream claim | Not run |

Save screenshots without attendees' faces or identifying device names unless permission covers them. Record the candidate manifest/source fingerprint with the image set. The R1 card requires a complete volunteer walk and matching evidence before the guide is signed off.
