Alfie operator guide

Beta 1.0 · build 4 · current single-camera window

Source-checked draft. The steps and labels below need a candidate walk on the actual rig. The two-input Multiview workflow is still integration work and is not described as available here.

Before starting

  1. Connect one camera or capture device. In the inspector, choose it under Source → Camera; use Refresh devices if needed.
  2. Open Settings → Composer and choose Stage for a distant stage subject or Webcam for a close video-call subject. Choose the shot preset there or in the running pill.
  3. Open Settings → Output. Select the Show Standard and Preferred Route (Virtual Camera or Program Display), then check the route's bring-up status. A display/switcher must be checked at its own input; an Alfie handoff count is not proof of presentation.
  4. Press Start session. Approve camera and virtual-camera extension prompts if the Mac presents them. If a prompt is refused, resolve it in System Settings and try again; installation on a clean Mac is not yet rig-verified.

Capture rate: Stage requires a camera format at the exact show rate and does not silently choose a slower rate. Webcam prefers that rate, but can use its fastest suitable HD format below it when none matches. The inspector shows the delivered size and capture-profile reason. Confirm downstream cadence separately.

Frame a subject

  1. Press Detect, then click the intended person in the wide source view. Cancel backs out before selection; Acquiring… means Alfie is gathering evidence.
  2. When the pill shows Locked, press Crop if needed. Stage has its shot preset ladder; Webcam has its own Wide/Tight choices.
  3. + Push in and − Pull out move one shot rung per tap. There is no hold-to-zoom control. A limited zoom message means the requested crop cannot be made safely from the source pixels.
  4. Manual moves the crop centre by clicking the picture. Auto Pan sweeps the crop. These modes own geometry while active; select Crop to return to tracking when a valid lock remains.

When tracking is lost

Pill labelMeaning and operator action
Pick subjectNo usable retained identity. Press Detect and tap the subject, or tap directly during recovery when offered.
Acquiring…Alfie is collecting a lock; wait or cancel the Detect flow.
LockedTracking has authority over the crop.
RecoveringDuring the 10-second subject HOLD, Alfie keeps the last good framing while looking for the same subject. You can tap a different person deliberately.
SearchingAfter HOLD, Alfie waits wide for the retained subject. Do not assume it has a new lock.
ResumeAvailable only with retained subject evidence. Press it to request tracking again; if evidence is gone, the action falls back to Pick subject. Resume does not switch a Manual/Pan mode silently.

Return to Wide shows the uncropped source and clears the lock; an old Resume cannot reactivate it. Use it when unsure of the subject, then pick a person again. Stop session ends capture and releases the virtual camera; the stopped screen offers Start session. The menu's Stop Session shortcut is ⌘⌥⇧S.

Check health and report a problem

  • Open the right-side Inspector → Pipeline stages for delivered, admitted, render, handoff and loss measurements. Downstream presented FPS is unknown to Alfie.
  • Inspector → Setup check is a short provisional check of the current source and route; it is not a hardware certification or 60-minute soak.
  • Find the files through Settings → Output → Diagnostics → Open in Finder. Each session has alfie_session_*.json, alfie_soak_*.csv and alfie_memory_*.csv in the sandboxed Documents/CinematicCore/Diagnostics folder.
  • For support, record the build/source fingerprint from the manifest, Mac/macOS, camera/capture device, delivered size/rate, show standard, output route, and exact steps. Review filenames, device names and notes before sharing diagnostic files.

The current project deployment target is macOS 26.2. Lower-OS support, the two-input operator console, downstream output cadence and on-rig recovery are not verified for this guide. See the R1 evidence runbooks and candidate screenshot checklist.
