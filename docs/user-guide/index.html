Alfie frames camera pictures into one Program feed. This guide covers the current Stage A/B workflow and the single-camera Webcam view.

Rehearse before a service

This draft matches source candidate 7691e6e. Screenshots, install walkthrough and real-camera/output qualification remain pending. Check the supplied build fingerprint before following these steps.

01 Get ready and start

This source candidate targets macOS 26.2 or later. Use the supplied candidate package and its installation instructions; its compatibility and release evidence must name your Mac, camera, capture device and output route. Rehearse before sending it live.

  1. Install Alfie from the supplied package into Applications. Allow camera access when requested. For Virtual Camera, complete the macOS system-extension approval if requested.
  2. In Stage format, the stopped screen shows Show setup. Choose Show standard and the Program output. Assign Camera A and, for two-input operation, a different device to Camera B.
  3. Choose Start with Camera A only or Start show · A Program, B Preview. Every new show starts with A as Program. Saved device choices do not restore the previous on-air roles.
  4. Confirm moving pictures, delivered resolution/rate and the actual receiving output. With two inputs, check both A and B before relying on Take.

A pair without a stored failure can currently start as an unmeasured trial. Alfie measures the pair after Start; a short check is not sustained-load certification. Treat a stored certification label as history until the current camera modes, delivered formats and output have been verified. C and D are reserved slots; this candidate’s setup operates A/B.

Webcam format uses the single-camera workflow: select the source in Inspector and use Start session. Do not assume the Stage two-input setup applies to that view.

02 Read Preview and Program

In Stage Multiview, Preview is on the left and Program is on the right. Program is the picture routed to the selected output. Preview is the other camera’s prepared shot; changing it does not put it on air.

The pane’s Shot view shows its framed result. Use Source on the camera being controlled to see the wide source, select a person or place a manual crop. Check camera letters and the pill’s target before each command.

With A alone, Program is A, there is no Preview camera, and Take is unavailable. Controls then act on the single Program camera. With two inputs, controls normally act on Preview.

03 Prepare, Take and Edit Live

  1. Prepare the Preview shot and confirm the intended camera/person in its picture.
  2. Read the status below Preview and the TAKE reason. A refused click shows why it could not commit; it does not queue a later cut.
  3. Press TAKE when you intend to send Preview to Program. On a successful Take the roles swap; the previous Program becomes Preview and controls follow the new Preview.

A moving shot can be legally Taken when the technical checks pass; there is no automatic director settlement requirement on manual Take. Confirm the movement is suitable yourself.

Edit Live deliberately targets Program. Framing changes then affect the live output. Check the red live-edit state and camera letter. Choose Done editing to return controls to Preview. Edit Live does not itself swap cameras, and a successful Take exits it.

There is no integrated Auto Director, automatic Take, microphone control or hardware motion in this candidate. The next-shot panel’s technical status does not authorize those features.

04 Choose a person, mode and shot

Choose Stage in Settings → Composer → Basic → Format. Its presets are Wide, Full Body and Waist Up. The Wide preset is a framed stage composition. Return to Wide shows the full source and clears the person lock on the camera currently controlled. In two-input operation that is usually Preview; it does not automatically widen Program.

Push in and Pull out are single taps for one complete shot step. No hold is needed. A repeated tap in the same direction during a move does not skip a step; the opposite direction reverses it. Direct preset selection and Return to Wide cancel the current move.

To follow someone, tap Detect, select them in the controlled camera’s Source view, and confirm the locked person in Shot view. Detection finds candidates; the operator chooses who to frame.

Manual lets you place the crop with a Source-view click. Auto Pan sweeps the stage without following people. These modes keep operator ownership; Detect is unavailable there. Return to Wide and select again, or use Crop to return to an available lock.

Webcam offers Wide and Tight. A distant person may reach the enlargement limit; ZOOM LIMITED is not evidence that identity is certain. Improve camera placement or delivered source quality.

05 Adjust headroom

Settings → Composer → Basic → Stage Headroom controls Full Body and Waist Up. Current defaults are 7% and 6%, with a 2–20% range. Change a small amount while checking the controlled camera’s Shot picture. Settings are saved; Reset Headroom to Defaults restores those values.

These are current controls, not evidence that a particular distant-subject shot is qualified. In Edit Live, watch Program and the receiver while changing framing.

06 Send one Program feed onward

In Settings → Output, choose Preferred Route and check Active Route. Program Display fills the selected display; verify its physical HDMI/converter/switcher path. Virtual Camera exposes Alfie as a camera input to a compatible receiving app after extension approval.

Set Show Standard to match the receiving system; current choices include 1080p50, 59.94 and 60. The standard is frozen for the running session, so change it before starting the next run. Set the display resolution/refresh separately in macOS and suppress notifications on the output display.

Two cameras still produce one routed Program feed. Alfie’s Preview is an internal preparation picture. A local pane or accepted frame count cannot prove downstream presentation. Verify the actual receiver, and do not treat a rehearsal output as a working external destination.

07 Recover and stop

Wrong or uncertain person
Check which camera the pill controls. Use Return to Wide there and select again. To change on-air framing with two inputs, prepare a safe Preview and Take it, or deliberately enter Edit Live and use Return to Wide on Program.
Preview missing or stale
Read the refusal reason and use Reconnect for that camera. Check power, device and cable. Do not expect Take to execute later by itself.
Program camera disappears
Watch the output status and actual receiver. There is no silent cut to the other camera. Choose a suitable available Preview and Take explicitly, or reconnect the affected camera. Fault handling is not a guarantee of uninterrupted downstream video.
No receiver picture
Check Active Route, chosen display/camera input, physical path and receiver standard. Rehearsal status means external output is unavailable.
End of show
Use Stop session to stop the whole show and confirm the stopped setup screen. Starting again begins A as Program. Collect diagnostics before discarding an affected run.

08 Collect feedback and data safely

Report source/build fingerprint, Mac/OS, camera and capture device, delivered size/rate, show standard, output route and the event time. Describe separately what happened in Source, Preview, Program, controls and the receiving output.

Settings → Output → Diagnostics → Session Log → Open in Finder opens the session diagnostics folder. Collect matching alfie_soak_*.csv, alfie_memory_*.csv and alfie_session_*.json. The Inspector’s Reveal logs in Finder opens a different folder containing extension/routing text logs. Neither button sends files automatically.

Review files before sharing: device names, build/machine details, timestamps, errors and clip paths can identify your setup. Optional Training Data recording stores person/body/pose/crop observations and camera metadata; it is not a video recording. Leave it off unless specifically authorized. Stop recording before removing its consent setting; removing consent is unavailable while recording. Use its deletion controls deliberately.

Screenshots and receiver recordings require permission from the people/site concerned. Source code checks do not replace a rehearsal or a real-camera qualification report.
