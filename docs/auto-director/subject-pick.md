# Subject pick and operator nomination · C-08

The Source pane shows the controller's current subject selection. “Alfie's pick · select to acquire” is a rule-selected suggestion; it has not begun acquisition. Acquiring, tracking, recovering and lost are separate actual camera states. “Your subject” identifies an operator nomination. Position hint and central presenter are selection rules, never inferred names, identity probabilities or readiness claims.

Click a person once in the full Source picture to nominate them. Candidate rectangles also have accessible selection buttons. The click uses normalized source coordinates; letterbox margins do nothing. Shot view carries the plain selection caption, while selection rectangles belong only to the full Source picture. Program changes continue to require explicit Edit Live. A nomination follows the existing operator command path and takes over Director authority; it grants no automatic handback.

`DirectorSection.subjectPicks` is a plain per-channel dictionary sampled by the existing console refresh at no more than 15 Hz. Each pick carries the channel, source generation, selection revision and route generation, current phase, candidate rectangles, selected candidate, provenance and current override permission. The display rejects nonfinite/out-of-frame geometry, duplicate candidate IDs, more than 32 boxes and contradictory selected states. Thirty-two is a defensive UI storage bound, not a workload budget or qualification threshold. Missing/ambiguous evidence never invents a selected person. A recovering rectangle is labelled last position.

The UI sends `DirectorSubjectOverrideRequest`, bound to the exact painted source, selection and route. The proxy checks the current attached controller before forwarding; the controller must independently recheck bindings, Preview/Edit Live ownership and source health before dispatching the ordinary nomination. A Take away and back changes the route generation and retires the old request. Unsupported controllers refuse the typed request instead of falling through to the legacy unbound method. Refusals remain visible in the Source pane.

In Debug, Window → Multiview Gallery → Subject pick · C-08 offers suggested, acquiring, operator tracking, ambiguous, recovering, lost and unavailable examples. Its interactive example emits one synthetic nomination change and advances its selection revision. It uses no camera, saved qualification or media. These gallery states and deterministic tests establish software behavior only. Discovery-rate calibration, rig soak, subject accuracy and live operator qualification remain separate work; this UI enables no automatic discovery.
