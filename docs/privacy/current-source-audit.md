### Diagnostic session ownership

Each new diagnostics session preserves the legacy local timestamp convention and adds a UUID token shared by its soak CSV, memory CSV and optional session manifest. One off-main writer queue exclusively creates the set before appending rows; an existing member refuses the attempt without appending to it or replacing it, and removes only members allocated by that failed attempt. Rapid Stop/restart and separate recorder instances cannot merge their sessions merely because they start in the same second. Closing metadata atomically updates the successfully reserved manifest. Existing thirty-day modification-time cleanup and its session-start trigger remain unchanged.

The detailed report and explicit metrics exporter accept both legacy timestamp-only filenames and the new full tokens. Companion matching uses the full token. If a folder contains multiple latest sessions in the same second, the detailed report requires an explicit CSV or manifest instead of choosing by UUID order. This is session-integrity behavior, not an additional consent or retention policy. Synthetic temporary-root regressions cover queued close/restart, multiple instances, pre-existing member preservation and partial-allocation cleanup; current candidate build evidence belongs to its batch report.

## Explicit metrics export

For a local support summary, select the exact session CSV yourself and choose a **new** JSON file in an existing folder outside the selected input folders:

```sh
python3 CinematicCoreMacOS/scripts/diagnostics_export.py \
  /path/to/alfie_soak_2026-10-21_123456.csv \
  --memory /path/to/alfie_memory_2026-10-21_123456.csv \
  --out /separate/export-folder/metrics.json
```

`--memory` is optional. Directory/newest-session inference, symlink inputs and existing destinations are refused. The exporter reads no adjacent files. It validates all selected CSVs before creating a mode-0600 output file; invalid rows, ambiguous headers/aliases, nonfinite or negative known metrics and unknown controlled states refuse the export without quoting file contents or paths in CLI errors. Missing/`unknown` measurements are omitted rather than invented as zero. Counters are parsed exactly as unsigned 64-bit whole numbers; fractional or out-of-range counters refuse rather than round. Relative elapsed seconds remain; downstream presentation remains explicitly unknown. Legacy combined drops retain a `legacy_mixed_drops_*` label.

`exportSchemaVersion: 1` contains the fixed kind/source-layout enums, `throughput` and optional `memory` metric rows, `presentedFPS: "unknown"` and fixed limitations. Unknown columns are discarded. No input manifest text becomes an allowlist. This tool produces a limited metrics projection, not the original evidence package, an anonymous dataset, a training/media export or authorization to share externally. Inspect the result and approve the recipient separately. `diagnostics_report.py` remains the detailed local evidence tool and still includes identifying context and notes.

### Recording persistence integrity — 22 October 2026 candidate

Training recording separates admitted observation sequence numbers from successfully persisted row totals. Backpressure and write failures remain losses; metadata totals are based on successful writes rather than rows submitted to a writer. Stop and consent revocation close admission immediately, drain outstanding writes, then persist the retained terminal buffer before metadata and close. This preserves the already admitted partial tail without adding an unbounded write queue. A failed partial append is truncated back to its prior boundary before another batch; rollback failure closes the writer and surfaces an error. An unrecoverable file can retain an incomplete tail, so successful-batch totals are not a power-loss or damaged-file completeness guarantee. Consent, retention defaults, data fields and cleanup triggers are unchanged. Synthetic writer fault/drain checks and final candidate results are recorded in the [batch report](../../reports/director-decision-evidence-2026-10-22/README.md).
