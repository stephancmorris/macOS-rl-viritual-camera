## Validation

Final Swift validation passed **1,038 definitions / 1,625 expanded executions**, zero failures and three existing opt-in hardware/fixture skips. Focused Stop/alias suites passed 16 definitions / 49 cases. Actual CoreML CPU interoperability was configured and passed. The unsigned Release app and extension build succeeded. Exact app source fingerprint, offline source hashes and skip identities are in [validation.json](validation.json).

All **184 selected Python unit tests** passed: 106 script tests with the fresh actual Swift bundles, plus 78 training tests in an isolated runtime. The training selection exercises real Gym environments, Torch datasets, actual SB3 deterministic actor inference and an in-memory trace, with no dependency skips. Six existing environment checks, including real SB3 check_env, also passed. Timing tests demonstrate .03 elapsed-time velocity versus the legacy .30 across a caller-accepted long edge; when explicitly marked discontinuous, the crossing expert pair is excluded. Golden legacy float32 observations/actions and terminal behavior remain unchanged. The trace check emits Torch's deprecation warning for the existing tracing API; parity passes. Existing Director scorer unit fixtures are regression evidence, not a new model-quality result.

The exact Release candidate was opened through native accessibility. It displayed Single Cam / Session Stopped and disabled Session → Stop Session. No capture was started. B-only and pending-start menu availability/reactivity are covered by unit tests; this GUI check does not establish those live states. A screenshot was unavailable, so the manual observation is accessibility-only.

Integration first exposed an inconsistent running-plus-starting fixture: its stable-origin snapshot refused capture while generic provenance still admitted the attempt. The shared source-classification helper now refuses starting sources, and all focused/full tests pass. Independent cross-review found the equal-clock future-credit defect and verified phase completeness, Stop ownership, bounded aliases, legacy timing parity, actor parity and split preflight. The earlier failed focused run and interrupted full run are superseded by the final passing runs; their logs remain in the temporary artifact folder.
